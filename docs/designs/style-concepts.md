# Pasoor Style Concepts

Saved visual reference:

![Pasoor stylesheet concepts](./pasoor-style-concepts.png)

## Concepts

1. Classic Green Felt
   - Deep green felt background
   - Cream cards
   - Gold accents
   - Traditional card-table feeling

2. Modern Light Table
   - Off-white background
   - Slate text
   - Subtle borders
   - Minimal shadows
   - Clean dashboard-style layout

3. Persian Tile
   - Restrained turquoise and ivory palette
   - Tile-inspired borders
   - Warm paper cards
   - Elegant but not visually busy

4. Dark Card Room
   - Charcoal background
   - Emerald highlights
   - High-contrast cards
   - Amber score badges
